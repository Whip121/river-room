# 河畔牌室 · River Room

中文德州扑克网页，2–10 人、真人与电脑混合、统一入场筹码、输光可补筹。

## 立即试玩

双击同包中的 `河畔牌室-本机试玩.html`，使用 Edge、Chrome 或 Firefox 打开，无需安装依赖。此文件只在当前页面与电脑对战，不支持跨设备加入，刷新会重开。

## 运行联机网页

需要 Node.js 20 或更新版本。项目没有第三方运行依赖，无需 npm install。

在此目录运行：

```sh
node server.mjs
```

也可以在安装 Node.js 后双击 `启动联机网页.cmd`。然后打开 `http://localhost:3000`。

1. 设置昵称、头像、2–10 个座位、圆桌或椭圆桌、统一入场筹码、大小盲、行动时间和电脑人数。
2. 创建房间；点击“复制邀请链接”。
3. 朋友从同一服务地址进入、填写昵称；房主点击“开始对局”。
4. 输光后点击“补筹”。每次补回房主设置的入场筹码，正在进行中的补筹会在下一手生效；如果本手赢回了筹码，则取消预约补筹。
5. 每手结束显示 5 秒输赢清单，随后回到保留上一手公共牌与摊牌的桌面；所有仍在座的真人点击“准备下一手”后自动发牌。

不同设备需要能访问运行此服务的电脑。在同一局域网内，使用该电脑的局域网 IP 代替 localhost。**localhost 链接不能发给异地朋友使用。** 异地对战需要把此服务部署到可公网访问的 Node.js 服务器，并使用其 HTTPS 地址。

## 服务器部署

环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| PORT | 3000 | HTTP 监听端口 |
| HOST | 0.0.0.0 | 监听地址 |
| DATA_DIR | 项目下的 data | 牌局保存目录 |

附带 Dockerfile，可使用容器运行。将 `/app/data` 挂载到持久存储；使用反向代理提供 HTTPS。

```sh
docker build -t river-room .
docker run -d --name river-room -p 3000:3000 -v river-data:/app/data river-room
```

当前服务适用于个人好友房、小规模单实例部署。**只运行一个实例**；多实例需要改成共享数据库与分布式房间锁。最多保存 200 个房间，当前不会自动删除历史房间。数据目录保存牌局和会话哈希，不要作为静态文件公开。

## 已实现

- 2–10 人；房主统一设置筹码、大小盲与 15/30/60 秒行动时间。
- 真人、电脑混合；各电脑独立选择简单、中等或困难。
- 无限注；过牌、跟注、弃牌、加注、全下与最低加注校验。
- 两人桌特殊盲注顺序，主池、边池、平局分池、零头和未跟注筹码退回。
- 电脑仅使用自己的底牌和公共信息。中等/困难使用不同采样数的蒙特卡洛胜率估计，属于启发式对手，不宣称达到职业水平。
- 服务端权威洗牌、发牌、结算；客户端不会收到对手未公开底牌和牌堆。
- 通过 HTTP 每秒同步；服务端串行处理同一房间操作，拒绝过期或重复下注。
- 同浏览器保存座位凭证；刷新重连。数据落盘，服务重启可恢复。
- 超时可过牌则过牌，否则弃牌；长期离线下一手暂离。
- 下一手入座，输光可补筹，电脑自动补筹，房主主动离开时转交房主。
- 每手结算清单显示所有参战者本手输赢与 5 秒倒计时；清单关闭后保留摊牌，等待全员准备。
- 手机窄屏使用双列座位；电脑可在开房时选择圆桌或椭圆桌。
- 长牌与短牌可在开房时选择。短牌使用 6–A 共 36 张，A-6-7-8-9 为顺子，同花大于葫芦。
- 房间满员后自动进入观战；观战者没有下注权限，页面显示当前观战人数。
- 每位玩家显示“当前筹码及本手已下注 − 累计带入”的总体输赢。
- 连续 3 手第一次行动即弃牌或全下会收到公开警告；连续到第 5 手时转为观战，座位由中等电脑接管。
- 管理员模式密码为 `126399`。管理员可查看全部底牌并主动关闭模式；开启时所有玩家和观战者都会看到醒目提示。
- 支持 HTTPS 微信头像图片链接和本地 PNG/JPEG/WebP 上传；本地图片会在浏览器中缩放压缩后保存。真正的微信 OAuth 授权仍需部署者配置微信 AppID、AppSecret、已备案回调域名和 HTTPS 公网地址。
- 昵称在服务端统一校验，拒绝常见侮辱词以及“某某的爸/妈/爹”等亲属冒充式名称。
- 下注筹码带入场动画；全下会显示高对比度闪烁边框与 `ALL IN!` 警示。

## 已验证与尚未验证

## 使用范围

仅使用虚拟筹码，无充值、提现或现金兑换。房间链接即邀请凭据；拿到链接的人可加入空位。第一版不含账户登录、房间密码、聊天、战绩排行榜或比赛升盲。
